# Fikria Dental Clinic

An AI-powered dental clinic management and appointment booking platform built with Next.js, Supabase, and Gemini AI.

## Features

- 🤖 AI Receptionist (Gemini AI)
- 📅 Smart Appointment Booking
- 👨‍⚕️ Doctor Dashboard
- 🏥 Admin Dashboard
- 👥 Patient Management
- 📊 Analytics Dashboard
- 🦷 Doctor & Service Management
- ❓ FAQ Management
- 📱 WhatsApp Notification Integration (In Progress)
- 🔒 Secure Authentication with Supabase

## Tech Stack

- Next.js 15
- TypeScript
- Tailwind CSS
- Supabase
- Google Gemini AI
- PostgreSQL

## Project Status

Production-ready MVP with appointment booking, AI receptionist, dashboard management, and scalable architecture for real dental clinics.
